# Sales-Order-Automation-Dashboard-UMKM-Peyek-Goyang
Digitalisasi dan otomatisasi pencatatan pesanan harian pada UMKM Peyek Goyang. Proyek ini mentransformasi buku rekapitulasi transaksi manual menjadi sistem basis data terstruktur di Microsoft Excel, lengkap dengan dynamic lookup pricing, validasi data input, serta interactive reporting dashboard.
